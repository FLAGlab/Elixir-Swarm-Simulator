# Development Guide

This is a web application written using the Phoenix web framework.

## MANDATORY: Read Documentation Before Any Change

**Before writing or modifying ANY code, you MUST read the relevant documentation in `docs/`:**

- **`docs/Architecture.md`** — Full system architecture, data flows, supervision tree, and design decisions
- **`docs/ProgramingGuide.md`** — All coding conventions, patterns, and rules
- **`docs/ALGORITHMS.md`** — Guide for implementing movement algorithms
- **`docs/MAPS.md`** — Guide for implementing simulation maps

**Do not skip this step.** These documents define how the project is built and must be followed.
